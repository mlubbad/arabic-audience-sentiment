`AGENTS.md` is the single source of instructions for every agent in this repository, Gemini
included. Read it first and follow it exactly; this file only points there so nothing is
duplicated or allowed to drift.

Then read `docs/agents/CONTEXT.md` (including **§10 Latest architecture & scalability updates**), `docs/adr/README.md` (`0001`–`0007`), and `docs/engineering/PLAYBOOK.md`, then your work order.
