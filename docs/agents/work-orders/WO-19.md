## Why
Competitor discovery (roadmap phase 2, which ships first by owner decision) classifies every channel into Main → Primary → Secondary genres. The classifier (WO B-1, later) reads the taxonomy from the database and constrains Gemini to its keys. This is the same pattern as `workspace_topics`, but platform-wide reference data, not per workspace. v1 has **level 1 only**. Levels 2 and 3 come as v2 after the owner reviews them.

## Design (decided)
```
public.genre_taxonomy_versions(version int primary key check (version > 0),
  published_at timestamptz not null default now(), notes text)
public.genre_taxonomy(version int not null references public.genre_taxonomy_versions,
  key text not null check (key ~ '^[a-z][a-z0-9_]{0,39}$'),
  parent_key text null, level smallint not null check (level between 1 and 3),
  name_ar text not null check (length(name_ar) between 1 and 80),
  name_en text not null check (length(name_en) between 1 and 80),
  description text not null check (length(description) between 1 and 400),
  iab_id text null, position int not null,
  primary key (version, key),
  foreign key (version, parent_key) references public.genre_taxonomy(version, key),
  check ((level = 1) = (parent_key is null)))
```
- A constraint trigger enforces **child level = parent level + 1**.
- RLS is enabled on both tables with no policies. `revoke all` from `public, anon, authenticated`.
- `public.genre_taxonomy(p_version int default null) returns jsonb` is `SECURITY DEFINER` with `set search_path = ''`. It takes the latest version when `p_version` is null, and the result is `{version, genres:[{key,parent_key,level,name_ar,name_en,description,iab_id,position}]}` ordered by `level, position`. Grant execute to `authenticated` and `service_role`, revoke from `public, anon`. An unknown version raises `invalid_input` (22023).
