## Why
After WO-20 the database can hold a channel's profile and daily stats, but nothing sends them. Every discover already calls `channels.list` once (`workers/python/src/collectors/youtube_api.py:357-360`, `part=contentDetails`). Asking for `contentDetails,snippet,statistics,brandingSettings,topicDetails` in **the same call costs the same 1 quota unit**. Discover runs once per plan `catalogue_interval` (1440 min by default, `20261018000000_channel_pause.sql:88-95`), so a channel gets a stats row about once a day.

## Tasks
1. In the catalogue method, request the five parts in the existing `channels.list` call and build a profile dict:
   - `external_channel_id`: the channel's id.
   - `description` from `snippet.description`; `country` from `snippet.country`; `default_language` from `snippet.defaultLanguage`; `channel_published_at` from `snippet.publishedAt`.
   - `keywords`: parse `brandingSettings.channel.keywords`, a space-separated string where phrases are double-quoted. `'طبخ "حلويات شرقية" وصفات'` gives `["طبخ","حلويات شرقية","وصفات"]`.
   - `topic_categories` from `topicDetails.topicCategories`, which are Wikipedia URLs.
   - `subscriber_count`, `view_count`, `video_count` from `statistics`. These are strings in the API, so convert them to int.
   - `subscriber_count_hidden` from `statistics.hiddenSubscriberCount`.
   - **Unknown is None, never 0 or `""`.** A part missing from the response leaves its keys **out** of the dict, which means "not observed" per WO-20. A hidden subscriber count gives `subscriber_count: None, subscriber_count_hidden: True`.
2. Return it as `Catalogue.channel`. Leave the video list logic and the `catalogue_channel_mismatch` guard (lines 366–420) as they are.
3. In the runner's discover path, after `commit_catalogue` succeeds, call `gateway.commit_channel(lease, catalogue.channel)` when the platform is YouTube and `channel` is not None.
   - If that commit fails, the discover finishes **`partial`** with error code `channel_profile_commit_failed`, never `succeeded` (invariant 2). The videos already committed stay. The next scheduled discover retries.
4. Python tests mock every HTTP call. A test writes `golden_channel.json` from the real builder, and the TS seam test commits it through PGlite and asserts the stored columns.
