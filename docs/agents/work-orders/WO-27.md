## Why

## Design (decided)
1. **Route `/competitors`**, scoped to the selected workspace. A channel picker lists the workspace's **YouTube** channels, from the same source the dashboard's channel filter uses. The selected channel lives in the URL (`?channel=<id>`).
2. **Header card: the selected channel.**
   - Its subscribers, views and videos, labelled **"from YouTube"** (`ar`: «من يوتيوب»). Unknown values show "—", never 0.
   - A `BudgetMeter`: "Tracked competitors: N of LIMIT", and "unlimited" when the limit is null.
3. **Suggestions**, one card per candidate, in the RPC's order:
   - the title, or the handle, or the id, linked to `https://www.youtube.com/channel/<id>` (opens a new tab, `rel="noopener"`);
   - source badges: "Featured by the channel" for `featured`, "Added by you" for `manual`;
   - subscribers, views and videos, or "—" for each unknown;
   - **"Match"**: the score as a percentage, labelled **"our estimate"** (`ar`: «تقديرنا»). This is policy: derived metrics must be labelled as ours.
     - A null score reads "Not enough data yet" (`ar`: «لا تكفي البيانات بعد»).
     - `profile_observed_at` null reads "Collecting this channel's public profile…" (`ar`: «نجمع الملف العام لهذه القناة…»).
   - **Tier badge**: `direct`, `indirect`, `aspirational` or `related`, with no badge when null. Show it as an outline badge with a one-line tooltip explaining the tier.
   - **Reasons**: render each `{kind, value}` through strings, for example "3 shared topics", "Same language", "Same country", "1.8× your size". Ignore unknown kinds; don't crash on them.
   - **Actions:** "Track" or "Stop tracking", and "Dismiss". The `competitor_limit_reached` error gives a toast naming the plan limit and linking to `/pricing`. Other errors give a toast with the stable code (PLAYBOOK: errors are never swallowed). Use optimistic UI only if it rolls back on error; otherwise refetch.
   - Only `workspace_owner` and `analyst` see the actions; a `viewer` sees a read-only page. Use the role source the account page already uses.
4. **Add a competitor**: one input for a link or handle, a Search button, and a confirm showing the resolved channel's name, then `competitor_candidate_add`.
   - Errors from `channel-lookup` reuse `account/channelLookupError.ts`.
   - Adding costs 1 quota unit for an id or handle and 100 for a search. Show the same cost hint `PublicHandleForm` shows.
5. **Empty and loading states**, via `pageStates/`: no YouTube channel in the workspace, no candidates yet ("Add a competitor, or wait for the channel's featured channels"), and loading skeletons.
6. **Demo mode:** in the fixture/demo shell the page shows an explanatory empty state, "Sign in and connect a channel to see competitors". There is no fake competitor data.
7. **Never show genres or YouTube category names as ours** (YouTube policy §3). This version shows none.
8. **RTL first**, with logical CSS properties, numbers via `n()`, and every string in both `ar.ts` and `en.ts`. Phone width: the cards stack and the actions stay reachable.

- [ ] A viewer sees no action buttons.

- [ ] An unknown reason kind doesn't crash the page.
- [ ] Arabic and English strings exist for every new key; the existing strings parity tests pass.
