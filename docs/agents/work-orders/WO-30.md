## Why
From the hashed members, compute how much two channels in one workspace share their engaged audience. Show it only:
- above privacy thresholds;
- with a confidence interval;
- on the plans the owner chose (decision 3, 2026-10-17: the two higher plans only);
- while the `audience_overlap` switch is on.

## Design (decided)
1. **Plan gate.**
   - Add `plans.audience_overlap boolean not null default false`.
   - Set it true for `agency`, `media`, `enterprise` and `owner`, the plans with 10, 25 or unlimited competitors.
   - Do the backfill inside `ALTER TABLE public.plans DISABLE TRIGGER plans_audited` / `ENABLE`, as `20261119000000` does. Without that, the admin_observability tests fail.
   - Helper `private.overlap_allowed(w uuid) returns boolean`: the workspace's active plan has `audience_overlap`.
2. **Cells.**
   - `private.audience_overlap_cells(workspace_id, channel_a uuid, channel_b uuid, a_size int, b_size int, shared int, computed_at timestamptz, primary key (workspace_id, channel_a, channel_b), check (channel_a < channel_b))`. Store one row per unordered pair and derive both directions.
   - `private.audience_sizes(workspace_id, channel_id, platform, size int, computed_at, primary key (workspace_id, channel_id))`.
   - `private.audience_universe(workspace_id, platform, size int, computed_at, primary key (workspace_id, platform))`. Its size counts distinct hashes on that platform in the workspace.
   - Every count excludes `is_suspected_bot`.
3. **History.** `private.audience_overlap_history(workspace_id, channel_a, channel_b, day date, a_size, b_size, shared, primary key (workspace_id, channel_a, channel_b, day))`.
   - Upsert today's row on each refresh.
   - The refresh deletes history older than 30 days (ADR-0003 §3: aggregates live 30 days until YouTube accepts).
   - **Counts and ratios only, never hashes.**
4. **Refresh.** `private.refresh_audience_overlap(budget interval default '2 minutes') returns int`.
   - Advisory lock, budget, a subtransaction per workspace.
   - **Switch off → returns 0.**
   - It processes workspaces that have members, ordered by oldest `computed_at` first (never-computed first).
   - Per workspace, recompute sizes, universe and all pairs with one grouped self-join on `(workspace_id, member_hash)`, `a.channel_id < b.channel_id`. Delete cells for pairs that no longer share anyone.
   - **Cron** `audience-overlap-refresh`, `*/30 * * * *`, guarded like the others, with `set local statement_timeout = '10min'`.
5. **`public.audience_overlap(p_channel uuid) returns jsonb`.**
   - `SECURITY DEFINER`, `search_path=''`. Revoke from public and anon; grant to authenticated.
   - **Checks, in this order:**
     - no channel, or `NOT private.has_role(ws)` → `forbidden`;
     - switch off → `feature_unavailable` (P0001);
     - `NOT private.overlap_allowed(ws)` → `plan_feature_unavailable` (P0001).
   - **Returns:**

     ```
     {status: 'ready'|'pending', computed_at, universe_size,
      thresholds: {min_audience: 100, min_shared: 10},
      channel: {id, title, platform, audience_size},
      others: [{channel_id, title, handle, platform, audience_size,
                below_threshold, shared, share_of_mine, share_of_mine_ci: {low, high},
                share_of_theirs, overlap_coefficient, affinity}]}
     ```
   - `others` are the workspace's **other channels on the same platform**.
   - `pending` means no size has been computed yet for this channel: `others` is `[]` and the numbers are null.
   - **Below threshold** is `audience_size(A) < 100` or `shared < 10`. Then `below_threshold = true` and **`shared` and every ratio are null, never 0** (invariant 3; ADR §5).
   - **Formulas** (round ratios to 4 places):
     - `share_of_mine = shared/|A|`;
     - `share_of_theirs = shared/|B|`;
     - `overlap_coefficient = shared/min(|A|,|B|)`;
     - `affinity = round(100 * (shared/|A|) / (|B|/|U|))`, null when `|U|` or `|B|` is 0;
     - `share_of_mine_ci` = the Wilson 95 % interval (z = 1.96) for `shared` successes out of `|A|`.
   - **Order:** `shared DESC NULLS LAST`, then `channel_id`.
6. **`public.audience_overlap_available(p_workspace uuid) returns jsonb`** → `{switch_on boolean, plan_allows boolean}`.
   - Membership is required; otherwise `forbidden`.
   - The web app uses it to decide whether to show the section at all. The owner's decision: the section is not shown on the lower plans.

## Acceptance criteria (each test fails on a named guard mutation; say which line)
- [ ] **Gates:**
  - another workspace's member gets `forbidden`;
  - with the switch off, `feature_unavailable`;
  - a `creator` plan gets `plan_feature_unavailable`;
  - `agency` and `owner` succeed;
  - `anon` cannot execute either RPC.
- [ ] **Thresholds:**
  - with |A| = 99 every other channel is below threshold, with null numbers;
  - with |A| = 100 and shared 9, below; with shared 10, shown;
  - nothing below threshold is ever 0.
- [ ] **Arithmetic**, hand-computed cases:
  - |A| = 200, |B| = 50, shared = 20, |U| = 1000 → share_of_mine 0.1, share_of_theirs 0.4, overlap_coefficient 0.4, affinity 200;
  - the Wilson bounds checked to 4 places.
- [ ] **Bots and platforms:** a suspected bot is not counted in any size or in `shared`; a channel on another platform is not listed.
- [ ] **Refresh:**
  - switch off → returns 0 and writes nothing;
  - a removed member updates the cell on the next run;
  - a pair that no longer shares anyone loses its cell;
  - `pending` before the first refresh.
- [ ] **History:** today's row is upserted (not duplicated) on two runs, and a 31-day-old row is deleted.
- [ ] **Plan backfill:** `audience_overlap` is true only for agency, media, enterprise and owner; `plans_audited` still records later admin edits.
- [ ] `npm run db:snapshot:check`, `npm run test:db` and `npm run check` pass (paste the summaries). No e2e.
