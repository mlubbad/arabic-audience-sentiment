Audience Sentiment (مشاعر الجمهور) — system architecture

Read-only use of YouTube Data API v3 on channels their owners connect through Google OAuth. No write endpoint is ever called.

1 · Channel owner's browser

React app (Arabic/English), app.sky-develop.net

  • Signs in (Supabase Auth)
  • Connects their own channel via Google consent
  • Chooses which videos to monitor
  • Reads dashboards, exports CSV
  • Can disconnect the channel or retire the workspace

2 · Control plane — Supabase (EU)

  • Postgres with row-level security: every table keyed by workspace; tenants cannot read each other
  • Edge functions: oauth-start, oauth-callback (tokens sealed AES-GCM at rest), worker gateway, billing webhook
  • Scheduler: decides which videos are due; the worker cannot widen the list
  • Metering: one unit per comment, charged once ever; plan limits enforced in SQL
  • Retention: comment text purged 30 days after collection (daily job); metadata refreshed on every check

3 · Worker (our server)

  • Receives a one-hour access token per job — never the refresh token
  • Reads YouTube for the due videos only
  • Sentiment: Arabic BERT model (CAMeLBERT-DA), on our own CPU
  • Topics: LLM classification of comment text
  • Writes results back through the gateway; idempotent batches

4 · YouTube Data API v3

Read only

  • channels.list (mine)
  • playlistItems.list
  • videos.list
  • commentThreads.list
  • comments.list

Scopes: youtube.readonly, youtube.force-ssl (required to read comments as the owner)

Google consent

Ownership is decided by channels.list(mine=true) on the granted token — never by a typed URL. Revocation (invalid_grant) stops all reads at once.

Quota discipline (per scheduled check)

① videos.list(part=statistics), 50 videos per unit → ② only videos whose commentCount moved are paged with commentThreads.list → ③ everything else is deferred to the next interval. Measured live: a second pass over 100 videos cost 2 units and read nothing.

Paddle (merchant of record)

Subscriptions and tax. Card data never touches this system; entitlements arrive by signed webhook.

What is stored

Video metadata & counts; comment id, author channel id, date, likes, text (30 days); our own labels. Never sold, never aggregated across users.
